
# Dhyaan - GitHub APK Build

## How to get APK (Free):
1. Create GitHub repo: dhyaan-apk
2. Upload all these files (drag whole folder)
3. Go to Actions tab -> Click "Build Dhyaan APK" -> Wait 4-5 min
4. Download artifact: app-debug.apk
5. Send to your coaching students via WhatsApp

## Permissions after install:
- Grant Usage Access
- Grant Notification Access (to capture YouTube titles)
- Disable battery optimization
